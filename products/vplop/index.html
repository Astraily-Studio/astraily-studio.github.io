Ctrl+Vを押したら、
それだけで終わる。

Vplop（ヴィプロップ）は、クリップボードにある画像データを、デスクトップやエクスプローラー上でCtrl+Vするだけで 実体ファイルとして保存するWindows常駐型ユーティリティです。 画面切り替えも、メニュー操作も、保存先の指定も必要ありません。

入手方法・お問い合わせ 機能を見る

解決する課題

Windowsでクリップボードの画像をファイルとして保存するには、これまで次のような手間がかかっていました。

  • Win+Shift+S でキャプチャ → 通知からプレビューを開く → 保存ボタンを押す → 保存先を指定
  • ペイントを開く → Ctrl+V で貼り付け → ファイル名・形式を指定して保存
  • 専用アプリに切り替える → 右クリックメニューからコマンドを選ぶ

Vplopは、これらの手順を「Ctrl+V一回」に集約します。

特徴

Ctrl+V一発保存

デスクトップやエクスプローラーで開いているフォルダに、クリップボード画像をそのまま保存します。

既存の操作を邪魔しない

画像データが無い場合や対象外のウィンドウでは、標準のCtrl+V動作をそのまま通します。

タスクトレイ常駐

専用ウィンドウは表示せず、設定はタスクトレイアイコンの右クリックメニューから完結します。

静かな通知

保存の成功・失敗はトースト通知でお知らせ。作業の邪魔をしません。

対応する画像形式

形式対応備考
PNG対応デフォルトの保存形式
JPEG対応有料版で保存形式として選択可能
BMP対応有料版で保存形式として選択可能
GIF（静止画）対応アニメーションGIFは非対応
